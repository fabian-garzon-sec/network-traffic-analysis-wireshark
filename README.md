# Análisis de Tráfico de Red con Wireshark

## Objetivo
Analizar la captura de paquetes para identificar la negociación de tres vías (TCP Three-Way Handshake) y validar la resolución de nombres vía DNS.

## Herramientas Utilizadas
* Wireshark
* Command Prompt / Terminal (ping, nslookup)

## Hallazgos / Pasos Realizados
1. Captura de tráfico HTTP/DNS.
2. Identificación de banderas SYN, SYN-ACK y ACK en el establecimiento de conexión TCP.
3. Inspección del encabezado IP y validación de puertos de origen y destino.
